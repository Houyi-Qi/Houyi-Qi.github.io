# Houyi Qi — Academic Homepage

Personal academic website: https://houyi-qi.github.io/

The site is a static HTML, CSS, and JavaScript website published from the root of the `main` branch through GitHub Pages. The root `.nojekyll` file enables direct publishing of these static files.

- `index.html`: profile, news, publications, education, service, and honors.
- `styles.css`: responsive layout and visual styles.
- `network.js`: interactive background network, with reduced-motion support.
- `assets/`: portrait, publication figures, university emblems, and profile icons.
- `SOURCES.md`: attribution for emblems and icons.

For local preview, run `python -m http.server 8000` from the repository root, then open http://localhost:8000/.

The earlier Jekyll sources and existing files remain in the repository for reference; GitHub Pages serves the root static homepage. The original `/about/` and `/about.html` URLs redirect to the homepage.
